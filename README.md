# Compliance Quality Assurance & Tests

## Sobre o repositório

Repositório destinado aos materiais e atividades práticas da disciplina de **QA**, com foco em Arquitetura Corporativa utilizando TOGAF ADM e ArchiMate.
Futuramente será atualizado para abordar novas atividades, aulas e conteúdos que forem ensinados.

## Sobre a disciplina

A disciplina aborda os fundamentos de Garantia da Qualidade de Software (SQA), modelos de maturidade (CMMI, MPS.BR, TMMi), normas ISO (ISO/IEC 25010), métricas de código e arquitetura corporativa.

## Atividade realizada: Diagrama TOGAF (Fases A e B)

Como parte dos estudos sobre o método **TOGAF ADM (Architecture Development Method)**, foi desenvolvido um diagrama ArchiMate contemplando as Fases A e B para um cenário de modernização de um sistema de gestão de entregas.

### Fase A – Arquitetura de Visão (Motivação)

| Elemento | Descrição |
|----------|-----------|
| **Stakeholders** | Cliente, Transportadora, Empresa de Logística, Área Financeira |
| **Drivers** | Ineficiência Operacional, Falta de rastreabilidade, Sistema Legado Obsoleto, Falta de Integração, Ausência de tecnologias para nuvem |
| **Goals** | Automatizar pedidos e entregas, Rastrear pedidos em tempo real, Integrar ERP, Migrar DB para nuvem |
| **Requirements** | Integração com ERP, DB em nuvem, Automatização de pedidos/entregas, Rastreamento em tempo real |

### Fase B – Arquitetura de Negócio

| Elemento | Descrição |
|----------|-----------|
| **Business Actors** | Operador logístico, Cliente, Transportadora |
| **Business Roles** | Cliente (utiliza/rastreia), Operador Logístico (gerencia produtos), Transportadora (gerencia entregas) |
| **Business Processes** | Utilizar serviço, Rastrear pedido, Gerenciar produtos, Realizar entregas |
